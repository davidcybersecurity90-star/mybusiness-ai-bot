# MyBusinessAI — Telegram-бот для малого бизнеса

AI-ассистент для бизнеса (на примере кофейни), который отвечает клиентам на вопросы о ценах, часах работы, и общается на произвольные темы через локальную LLM.

## Возможности
- Отвечает на вопросы о прайсе и меню
- Сообщает часы работы
- Приветствует пользователей
- Отвечает на произвольные вопросы через локальную ИИ-модель (Ollama, llama3.2)
- Логирует все диалоги (пользователь → вопрос → ответ)
- Устойчив к сбоям (обработка ошибок при недоступности ИИ)

## Технологии
Python, aiogram, Ollama, python-dotenv

## Как запустить
1. `pip install -r requirements.txt`
2. Установить и запустить [Ollama](https://ollama.com), скачать модель: `ollama run llama3.2`
3. Создать `.env` файл с `BOT_TOKEN=ваш_токен_от_BotFather`
4. `python bot.py`
